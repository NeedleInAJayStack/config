# Be Concise

- **State facts directly and skip narration**. "Changed auth.py to use JWT." not "I've updated the authentication module to now utilize JSON Web Tokens."
- **One-line summaries for small changes**. "Added POST /api/login endpoint."
- **Be concise**. When questions are straightforward, respond in 1-3 sentences. When the situation is nuanced or detail is requested, longer reponses are allowed but must be direct.
